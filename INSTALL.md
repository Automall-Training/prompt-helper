# Скиллы Automall для Codex

**prompt-helper** — универсальный помощник постановки задачи. Он задаёт вопросы по одному, показывает сводку «Я понял так… Верно?» и выдаёт один готовый промпт для нового чата. Про другие скиллы он не знает: нужный допишите в начало промпта сами. **fact-check** проверяет факты и расчёты в ответе ИИ. **analitik** — финансовый аналитик для всех, кто работает с данными, таблицами и Excel: своды, факт и план, маржа, «что если», склад, реклама, накладные в 1С, сверки, проверка таблиц. **one-big-feature** — большая задача силами нескольких агентов: свой скилл, программа, автоматизация.

## Установка на компьютер

Если вы открыли страницу с телефона, перешлите себе ссылку и откройте её на компьютере, где пользуетесь Codex.

Скопируйте весь текст из блока ниже и отправьте **одним сообщением в чат Codex**.

```text
$skill-installer Установи мне скиллы для использования в любых проектах:
1. prompt-helper из https://github.com/Automall-Training/prompt-helper
2. fact-check из https://github.com/Automall-Training/fact-check
3. analitik из https://github.com/Automall-Training/analitik
4. one-big-feature из https://github.com/Automall-Training/one-big-feature

В каждом репозитории скилл лежит в корне (путь "."), ветка main.
Имя каждого скилла совпадает с именем репозитория.
Если скилл уже установлен, сохрани его и продолжи со следующим.
Сообщи результат для каждого скилла.
```

После установки откройте **новую** сессию Codex: новые скиллы видны только в ней. Если у вас стоят старые `buhgalter` и `finansist`, удалите их папки из `~/.agents/skills`: их заменил `analitik`.

## Попробуйте после установки

- **Поставить задачу** — `$prompt-helper Хочу, чтобы ИИ сравнил два предложения поставщиков шин и сделал таблицу с ценой, сроком поставки и условиями гарантии.` Отвечайте на вопросы помощника по одному; готовый промпт вставьте в новый чат Codex.
- **Проверить расчёт** — `$fact-check Проверь расчёт в моём черновике. Старая цена шины — 1 000 леев, новая — 850 леев. В черновике написано, что скидка составила 20 %.`
- **Финансы** — `$analitik Сравни продажи за прошлую неделю с планом и с той же неделей прошлого года.`
- **Бухгалтерия** — `$analitik Перенеси накладные из этой папки в таблицу для импорта в 1С. Ошибки вынеси на отдельный лист.`

Перед первой работой впишите правила своей компании в `references/pravila-kompanii.md` скилла `analitik` (кто читает отчёты, пороги, НДС, шаблон 1С, кто решает спорное). Пустые пункты скилл спросит сам.
